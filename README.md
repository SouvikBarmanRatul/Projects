## 🚀 Featured Projects

### 01. Drone-Based Transmission Line Inspection & Vegetation Monitoring System[cite: 2]

* **Course & Code:** EEE359 – Engineering Project Management[cite: 1]
* **Institution:** Department of EEE, BRAC University[cite: 1]
* **Domain:** Unmanned Aerial Vehicles (UAVs), Artificial Intelligence, GIS Mapping[cite: 2, 4, 7]

**Project Brief:**  
An automated aerial inspection platform designed for high-voltage (~132 kV) transmission corridors in Bangladesh[cite: 2, 4]. The system utilizes VTOL UAVs fitted with dual RGB and thermal sensors, combined with machine learning models to detect equipment damage and tree encroachment risks[cite: 2, 3, 7].

**Key Deliverables:**
* **Aerial Inspection SOP:** Flight protocols and sensor payload integration[cite: 7, 8].
* **AI Computer Vision Model:** Automated detection of damaged grid hardware and vegetation hazards[cite: 2, 3].
* **GIS Mapping Dashboard:** Geo-referenced fault coordinates for utility maintenance teams[cite: 3, 4].

**Access Project Files:**
