## 📌 Project Overview

This repository holds the project documentation and resources for an automated, drone-based aerial inspection system tailored for high-voltage transmission lines and vegetation monitoring in Bangladesh[cite: 2]. 

By pairing VTOL UAVs equipped with RGB/thermal sensors with AI detection models, the system automatically identifies hardware faults and overgrown tree risks to keep power lines reliable and field personnel safe[cite: 2, 3, 7].

---

## ✨ Key Features

* 🚁 **Automated Aerial Patrols:** Safely scans rural transmission line corridors without risky manual pole climbing[cite: 3].
* 🤖 **AI-Powered Diagnostics:** Detects damaged hardware (e.g., cracked insulators) and vegetation encroachment[cite: 3].
* 📍 **GIS Dashboard:** Visualizes precise GPS fault coordinates for ground maintenance teams[cite: 3, 4].
* ⏱️ **Efficiency:** Cuts traditional inspection time by 50% and reduces maintenance costs[cite: 3].
